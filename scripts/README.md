# Набор автономных PowerShell-скриптов оптимизации Windows

В данной директории содержатся 50 готовых скриптов PowerShell для тонкой настройки, тюнинга и обслуживания системы без запуска графического интерфейса.

## Категории скриптов

### 1. Система и быстродействие
- `System-Tweaks.ps1` — глобальная оптимизация планировщика, памяти и отклика ОС.
- `Ultra-Tweaks.ps1` — экстремальный твикинг для максимального снижения задержек.
- `heapType.ps1` — калибровка сегментов кучи Windows.
- `iconSpacing.ps1` — настройка компактных отступов между значками рабочего стола.
- `drawingFont.ps1` — тонкая настройка субпиксельного сглаживания шрифтов.

### 2. Сеть и сетевой стек
- `Network-Tweaks.ps1` — оптимизация TCP/IP, Nagle, BBR/CUBIC, MTU и сокетов.
- `QoS-Policy.ps1` — политики QoS и приоритезации игрового трафика.
- `Blocklist-Manger.ps1` — управление списками блокировки нежелательных узлов.
- `wfRules.ps1` — аудит и оптимизация правил брандмауэра Windows.

### 3. Графика и игры
- `NVIDIA-Tool.ps1` — оптимизация настроек драйвера NVIDIA и параметров реестра.
- `nvcpl.ps1` — запуск Панели управления NVIDIA строго по требованию.
- `NVFetch.ps1` — проверка и обновление драйверов видеокарты.
- `NV-CS2-Tool.ps1` — специализированный профиль задержек и flip-queue для CS2.
- `NV-VALORANT-Tool.ps1` — профиль минимального инпут-лага для Valorant.
- `NV-Fortnite-Tool.ps1` — оптимизация для Fortnite.
- `NV-OW-Tool.ps1` — оптимизация для Overwatch.
- `NV-Marvel-Tool.ps1` — оптимизация для Marvel Rivals.
- `Steam-Config.ps1` — тонкая настройка конфигурации клиента Steam.

### 4. Конфиденциальность и безопасность
- `Privacy-Tweaks.ps1` — отключение телеметрии, маяков сбора данных и диагностических логов.
- `Security-Tweaks.ps1` — настройка политик безопасности, SmartScreen и динамической блокировки.
- `Debloat-UWP.ps1` — удаление предустановленных неиспользуемых приложений Windows.
- `Nuclear-Debloat.ps1` — глубокая очистка компонентов и фоновых служб.

### 5. Обслуживание и очистка
- `Cleaner-Tweaks.ps1` — очистка DNS-кэша, WinINet, временных файлов и кэша шейдеров.
- `CL.ps1` — быстрая экспресс-очистка логов и мусора.
- `Backup-SystemState.ps1` — создание резервной копии состояния реестра и служб.
- `Restore-SystemState.ps1` — откат и восстановление состояния системы.
- `Backup-KernelOS.ps1` / `Restore-KernelOS.ps1` — бэкап и откат параметров ядра.

## Запуск
Скрипты запускаются от имени Администратора в среде PowerShell 5.1+:
```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\System-Tweaks.ps1
```
